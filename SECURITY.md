# Security policy

Do not commit `.env`, `config.yml`, audit logs, member lists, QR codes, API keys, QQ cookies, or NapCat session data.

Use a dedicated QQ account, grant only the minimum group permissions, keep destructive actions disabled until rules have been reviewed in dry-run mode, and restrict administrator commands to explicit QQ allowlists. This project uses an unofficial OneBot implementation and may be affected by QQ account controls or upstream changes.

Report vulnerabilities privately to the repository maintainer. Include a minimal reproduction without real member data or credentials.
